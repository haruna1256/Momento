## Momento

「瞬間を、思い出に。」
Momentoは、場所と時間を軸に思い出を整理・共有できる 体験型アルバムアプリ です。
家族や友達と写真を共有しながら、過去と現在を比較し、日常の変化や物語を楽しむことができます。

## 特徴

場所 × 時間 × 写真 で思い出をカード表示

Before/Afterスライダーで変化を体験

よく使うアルバムをトグルで切り替え

マップ画面で撮影場所を一覧表示

## 技術スタック

フロントエンド：Swift (SwiftUI)

バックエンド：go supabase

デザイン：Figma（モバイルUI設計）

## 開発の目的

思い出の振り返りに「物語性」を持たせる

シンプルなUI/UXで写真整理を直感的に

個人開発プロジェクトとして、モバイル開発スキルを磨く
